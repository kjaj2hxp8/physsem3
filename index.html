১. তড়িৎস্থিতিবিদ্যা (Electrostatics)

F = k q₁q₂ / r² ; k = 1 / 4πε₀ ≈ 9×10⁹ N·m²·C⁻² F: বল, q: বিন্দু আধান, r: দূরত্ব
E = F / q₀ = k q / r² E: তড়িৎ ক্ষেত্র তীব্রতা, q₀: পরীক্ষাণ আধান
E_net = Σ Eᵢ superposition নীতি — বহু আধানের ক্ষেত্র যোগফল
বৈদ্যুতিক দ্বিধ্রুব (Electric Dipole) p⃗ = q·2l⃗ ; |p| = q·2l p: দ্বিধ্রুব আঘাত, 2l: দুই আধানের মধ্যবর্তী দূরত্ব
E_axial = (1/4πε₀)·2p / r³ অক্ষ বরাবর বিন্দুতে ক্ষেত্র; r: দ্বিধ্রুব থেকে দূরত্ব
E_eq = (1/4πε₀)·p / r³ লম্ব সমদ্বিবাজক বরাবর ক্ষেত্র
τ = p × E = pE sinθ τ: বলাঘূর্ণন, θ: দ্বিধ্রুব ও E-র মধ্যে কোণ
V = k q / r = (1/4πε₀)·q/r V: বিন্দু আধানের তড়িৎ বিভব
V = (1/4πε₀)·(p cosθ)/r² দ্বিধ্রুবের জন্য বিভব; θ: অক্ষের সঙ্গে কোণ
E = – dV / dr ক্ষেত্র ও বিভবের সম্পর্ক
U = (1/4πε₀)·q₁q₂/r U: দুই বিন্দু আধান ব্যবস্থার বিভবশক্তি
U = – pE cosθ দ্বিধ্রুবের tৎশক্তি; θ: দ্বিধ্রুব ও E-র মধ্যে কোণ
Gauss-এর উপপাদ্য ও প্রয়ােগ Φ = ∮ E⃗ · dA⃗ = q_enclosed / ε₀ Φ: বিদ্যুৎ ফ্লাক্স; A: সমতল ক্ষেত্রফল
E = λ / (2πε₀ r) অসীম দীর্ঘ সরল তারের কারণে; λ: রৈখিক আধান ঘনত্ব
E = σ / (2ε₀) একসমান আধানযুক্ত অসীম সমতল পাত; σ: ক্ষেত্রফল আধান ঘনত্ব
E_out = (1/4πε₀)·Q/r² ; E_in = 0 সম্পৃক্ত গোলকীয় খোলস; r: কেন্দ্র থেকে দূরত্ব
E_solid,in = (1/4πε₀)·Qr/R³ একসমান আধানযুক্ত গোলক; R: ব্যাসার্ধ, r≤R: ভেতরের দূরত্ব
ধারকত্ব (Capacitance) C = Q / V C: ধারকত্ব, Q: আধান, V: বিভব পার্থক্য
C = ε₀ A / d সমান্তরাল পাত ধারক; A: ক্ষেত্রফল, d: পাতের ব্যবধান
C' = κ C₀ = κ ε₀ A / d পারাবৈদ্যুতিক মাধ্যমে; κ = ε_r: পরাবৈদ্যুতিক ধ্রুবক
1/C_s = 1/C₁ + 1/C₂ + ... শ্রেণী সংযােগে সমতুল্য ধারকত্ব
C_p = C₁ + C₂ + ... সমান্তরাল সংযােগে সমতুল্য ধারকত্ব
U = ½ C V² = ½ Q V = Q² / (2C) U: ধারকে সংগৃহীত শক্তি
u = ½ ε₀ E² u: ক্ষেত্রের শক্তি ঘনত্ব (vacuum)

২. তড়িৎপ্রবাহবিদ্যা (Current Electricity)

I = dQ / dt = n e A v_d I: তড়িপ্রবাহ, n: মুক্ত ইলেক্ট্রনের সংখ্যা ঘনত্ব, v_d: ড্রিফ্ট বেগ
v_d = e E τ / m = e V τ / (m l) v_d: ড্রিফ্ট বেগ, τ: সঞ্চারণ কাল, m: ইলেক্ট্রনের ভর
V = I R Ohm-এর সূত্র; V: বিভব, I: প্রবাহ, R: রোধ
R = ρ l / A ρ: আপেক্ষিক রোধ, l: দৈর্ঘ্য, A: অপরছেদ ক্ষেত্রফল
σ = 1 / ρ ; G = 1 / R ; J = σ E σ: চালকত্ব; G: পরিবাহিতা; J: প্রবাহ ঘনত্ব
ρ_t = ρ₀ [1 + α (t – t₀)] α: তাপমাত্রা সহগ, t: তাপমাত্রা
R_s = R₁ + R₂ + ... ; 1/R_p = 1/R₁ + 1/R₂ + ... শ্রেণী ও সমান্তরাল রোধ সংযােগ
ε = W / q ; V = ε – I r ε: EMF, W: কাজ, q: আধান, V: টার্মিনাল বিভব, r: অভ্যন্তরীণ রোধ
I = n ε / (R + n r) nটি একই কোষ শ্রেণী সংযােগে; R: বহিঃস্থ রোধ
I = m ε / (R + r / m) mটি একই কোষ সমান্তরাল সংযােগে
I = m n ε / (m R + n r) মিশ্র সংযােগ (m সারি × n কোষ প্রতি সারিতে)
Σ I = 0 ; Σ ε = Σ I R Kirchhoff-এর জংশন নিয়ম ও লুপ নিয়ম
P/Q = R/S Wheatstone bride ভারসাম্য; P,Q,R,S: চারটি বাহু
P/Q = l / (100 – l) মিটার ব্রিজে; l: শূন্য বিন্দুর দৈর্ঘ্য (cm)
ε₁/ε₂ = l₁/l₂ পোটেনশিওমিটারে দুই কোষের EMF তুলনা
r = R (l₁/l₂ – 1) পোটেনশিওমিটারে অভ্যন্তরীণ রোধ মাপন; l₁: খোলা, l₂: R সংযেগে

৩. বিদ্যুৎপ্রবাহের চুম্বকীয় প্রভাব ও চুম্বকত্ব

Biot–Savart ও Ampere dB = (μ₀/4π)·I dl sinθ / r² Biot–Savart; dl: ক্ষুদ্র তারের দৈর্ঘ্য; r: দূরত্ব; θ: dl ও r-র মধ্যে কোণ
B = (μ₀I / 4πa)(sin φ₁ + sin φ₂) সীমাবদ্ধ সরল তার; a: লম্ব দূরত্ব; φ₁,φ₂: প্রান্তিক কোণ
B = μ₀ I / (2π a) অসীম সরল তারের কারণে
B = μ₀ I / (2 R) বৃত্তাকার প্যাঁচের কেন্দ্রে; R: বৃত্তের ব্যাসার্ধ
B_axial = μ₀ I R² / [2(R²+x²)^(3/2)] বৃত্তাকার প্যাঁচের অক্ষ বরাবর; x: কেন্দ্র থেকে দূরত্ব
∮ B⃗ · dl⃗ = μ₀ I_enclosed Ampere-এর পরিভ্রমণ সূত্র
B = μ₀ n I ; n = N / l সলেনয়েডের ভেতরে; n: একক দৈর্ঘ্যে প্যাঁচ সংখ্যা
B = μ₀ N I / (2π r) = μ₀ n I টরয়েডের ভেতরে; N: মোট প্যাঁচ, r: মধ্যবর্তী ব্যাসার্ধ
Lorentz বল ও পরিবহন F = q (E⃗ + v⃗ × B⃗) Lorentz বল; q: আধান, v: বেগ, B: চুম্বক ক্ষেত্র
F = q v B sinθ শুধু চুম্বক ক্ষেত্রে চলমান আধানের উপর বল; θ: v ও B-র মধ্যে কোণ
r = m v / (q B) লম্ব চুম্বক ক্ষেত্রে বৃত্তাকার পথের ব্যাসার্ধ
ν = q B / (2π m) = ω / 2π Cyclotron কম্পাঙ্ক; ν: কম্পাঙ্ক, ω: কৌণিক কম্পাঙ্ক
K_max = q² B² R² / (2 m) Cyclotronে সর্বোচ্চ গতিশক্তি; R: dees-এর সর্বোচ্চ ব্যাসার্ধ
F/l = μ₀ I₁ I₂ / (2π d) দুই সমান্তরাল তারের মধ্যে বল/দৈর্ঘ্য; d: তাদের মধ্যে দূরত্ব
τ = N I A B sinθ = M B sinθ সমান চুম্বক ক্ষেত্রে ক্যারেন্ট লুপের বলাঘূর্ণন; M=NIA: দ্বিধ্রুব আঘাত
গ্যালভানোমিটার, অ্যামিটার, ভোল্টমিটার I_s = N A B / k ; V_s = N A B / (k R) I_s: প্রবাহ সংবেদনশীলতা; V_s: বিভব সংবেদনশীলতা; k: ঘূর্ণন স্থিরাঙ্ক
S = I_g R_g / (I – I_g) S: শান্ট রোধ; I_g: গ্যালভানোমিটার সর্বোচ্চ প্রবাহ; R_g: গ্যালভানোমিটার রোধ
R = (V / I_g) – R_g ভোল্টমিটার তৈরিতে সংযুক্ত রোধ; V: পরিমাপ্য সর্বোচ্চ বিভব
চুম্বক দ্বিধ্রুব ও ভূ-চুম্বকত্ব μ_l = – e L / (2 m) ; |μ_l/L| = e / (2 m) প্রদক্ষিণে ইলেকট্রনের চুম্বক দ্বিধ্রুব আঘাত; L: কৌণিক ভরবেগ
B_axial = (μ₀ / 4π)·2M / r³ দন্ড চুম্বকের অক্ষ বরাবর ক্ষেত্র; M: চুম্বক দ্বিধ্রুব আঘাত
B_eq = (μ₀ / 4π)·M / r³ দন্ড চুম্বকের লম্ব সমদ্বিবাজক বরাবর ক্ষেত্র
τ = M B sinθ ; U = – M B cosθ চুম্বক দ্বিধ্রুবের বলাঘূর্ণন ও tৎশক্তি; θ: M ও B-র মধ্যে কোণ
I = M / V ; B = μ₀ (H + I) ; χ = I / H ; μ_r = 1 + χ I: আরোপণ; H: ক্ষেত্র তীব্রতা; χ: সংবেদনশীলতা; μ_r: আপেক্ষিক চালকত্ব
B_H = B cos δ ; B_V = B sin δ ; tan δ = B_V / B_H ভূ-চুম্বক ক্ষেত্র; B_H: অনুভূমিক, B_V: উল্লম্ব; δ: dip কোণ

৪. তড়িৎচুম্বকীয় প্রেরণ ও প্রত্যাবর্তী তড়িৎ

তড়িৎচুম্বকীয় প্রেরণ (EMI) ε = – dΦ / dt = – N dΦ / dt Faraday-এর সূত্র; Φ: চুম্বকীয় ফ্লাক্স, N: ফ্যাস সংখ্যা
ε = B l v গতিশীল পরিবাহীর প্রেরিত EMF; l: কার্যকর দৈর্ঘ্য, v: বেগ
ε = ½ B ω l² একপ্রান্তে ঘূর্ণনরত লঘু পরিবাহীর EMF; ω: কৌণিক বেগ
Φ = L I ; ε = – L dI / dt L: আত্ম-প্রেরকত্ব; ε: আত্মপ্রেরিত EMF
L = μ₀ N² A / l = μ₀ n² A l সলেনয়েডের আত্ম-প্রেরকত্ব; n=N/l: দৈর্ঘ্য অনুপাতিক প্যাঁচ সংখ্যা
Φ₂ = M I₁ ; ε₂ = – M dI₁ / dt M: পারস্পরিক প্রেরকত্ব; ε₂: দ্বিতীয় কুণ্ডলিতে প্রেরিত EMF
M = μ₀ N₁ N₂ A / l দুই সমাক্ষ সলেনয়েডের পারস্পরিক প্রেরকত্ব
প্রত্যাবর্তী তড়িৎ (AC) V = V₀ sin ωt ; I = I₀ sin(ωt ± φ) V₀,I₀: শিখর মান; ω=2πν: কৌণিক কম্পাঙ্ক; φ: পর্যায় পার্থক্য
V_rms = V₀ / √2 ; I_rms = I₀ / √2 মূল বর্গমধ্য মান (RMS)
X_L = ω L = 2π f L ; X_C = 1/(ω C) = 1/(2π f C) X_L: প্রেরণিক প্রতিবাধ্য; X_C: ধারক প্রতিবাধ্য; f=ν: কম্পাঙ্ক
Z = √[ R² + (X_L – X_C)² ] LCR শ্রেণী বর্তনীর প্রতিবাধ; Z: impedance
tan φ = (X_L – X_C) / R φ: V ও I-র মধ্যে পর্যায় পার্থক্য কোণ
I₀ = V₀ / Z ; I_rms = V_rms / Z LCR বর্তনীতে Ohm-এর সদৃশ সূত্র
ω₀ = 1 / √(LC) ; f₀ = 1 / (2π √(LC)) অনুসংহার কম্পাঙ্ক; ω₀: কৌণিক অনুসংহার কম্পাঙ্ক
Q = ω₀ L / R = 1/(ω₀ C R) = (1/R)√(L/C) Q: অনুসংহারের গুণমান (quality factor)
P_avg = V_rms I_rms cos φ = I²_rms R AC বর্তনীতে গড় শক্তি; cos φ: শক্তি গুণক
cos φ = R / Z = P / (V_rms I_rms) শক্তি গুণক; φ: পর্যায় পার্থক্য
I_wattless = I sin φ = I (X / Z) শক্তিহীন প্রবাহ; X = X_L – X_C
ω = 1 / √(LC) LC দোলকের আদর্শ কম্পাঙ্ক (qualitative)
ট্রান্সফরমার V_s / V_p = N_s / N_p = I_p / I_s (আদর্শ) V_s,V_p: মাধ্যমিক/প্রাথমিক বিভব; N_s,N_p: প্যাঁচ; I_s,I_p: প্রবাহ
η = (V_s I_s) / (V_p I_p) η: দক্ষতা; আদর্শ ট্রান্সফরমারে η ≈ 1

৫. তড়িৎচুম্বকীয় তরঙ্গ (Electromagnetic Waves)

I_d = ε₀ dΦ_E / dt I_d: স্থানপরিবর্তন প্রবাহ; Φ_E: বিদ্যুৎ ফ্লাক্স
∮ B⃗ · dl⃗ = μ₀ I_c + μ₀ ε₀ dΦ_E / dt Ampere–Maxwell-এর সূত্র; I_c: পরিবাহন প্রবাহ
c = 1 / √(μ₀ ε₀) ≈ 3×10⁸ m/s শূন্য স্থানে EM তরঙ্গের বেগ
v = 1 / √(μ ε) = c / n ; n = √(μ_r ε_r) মাধ্যমে বেগ; n: প্রতিসরাঙ্ক; μ_r: আপেক্ষিক চুম্বকধর্মী ধ্রুবক
c = ν λ ; E₀ / c = B₀ ν: কম্পাঙ্ক; λ: তরঙ্গদৈর্ঘ্য; E₀,B₀: তড়িৎ ও চুম্বক শিখর ক্ষেত্র
u = ½ ε₀ E² + B²/(2μ₀) = ε₀ E²_avg u: ক্ষেত্রের শক্তি ঘনত্ব
I = u_avg · c = ½ ε₀ E₀² c I: তীব্রতা (intensity) = শক্তি প্রবাহ / ক্ষেত্রফল
p = U / c ; P = I/c (শোষণে); P = 2I/c (প্রতিফলনে) p: ভরবেগ; P: চাপ; U: শক্তি, I: তীব্রতা
EM স্পেকট্রাম (কম্পাঙ্ক বাড়লে শক্তি বাড়ে):
রেডিও (বৃহত্তম λ) → মাইক্রোওয়েভ → IR → দৃশ্যমান → UV → X-ray → গামা (ক্ষুদ্রতম λ)
